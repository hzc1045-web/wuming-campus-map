# 数据与功能限制

- 校区名称和地点相对位置依据校园参考资料手工整理；正式用途和学院归属以学校现场信息为准。
- 模型不是测绘成果：建筑立面、高度、地形与树木为程序化示意。未将源图坐标配准为 WGS84 或其他地理坐标系。
- 不包含实时定位、精确步行路线或实景全景照片。“校园巡游”指围绕三维模型旋转。
- Google 对照使用完整校区名称查询在线卫星模式。连接失败会显示提示，不自动替换为其他服务。
- 在本版制作环境中，Google 主站、香港入口及浏览器访问均超时；实际卫星影像加载和道路/楼体校准尚未完成。在线检测只证明主站是否可连接，不保证影像子资源加载。
- Google 对照需要联网；其他地图功能及 Three.js 依赖在本地运行。高密度三维植被需要支持 WebGL 的现代浏览器，老设备可切换平面图。
- 自带服务器用于本机预览，默认仅监听 127.0.0.1。不是已部署的公开网站。
